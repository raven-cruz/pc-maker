# PC Maker
A game where you make a PC and learn about the components as you go.

# To play
1. clone this repo (or download)
2. open `./game/game.ipynb` in a Jupyter Notebook

For the win audio to play, you will need your own Google cloud platform API keys, stored in `./keys/service.json`. Without it, the rest of the game still works - just no epic win jingle.
